# Sacrifice of Praise 26 – Cinematic Motion Flyer (first draft)

Prayer Paradigm Ministry International · 1080 × 1350 · 30 fps · **30 s** (≈20 s build + ≈10 s held ending) · soundtrack: first 30 s of `audio/*.mp3`, 3 s fade-out. The earlier 56.6 s cut is in git history (`e02ab97`).

React + Vite + GSAP. The flyer is rebuilt from the original 34 PSD layers (positions, stacking and blend modes
verified against `final flyer.jpg`), animated on a single deterministic timeline synchronised to the supplied MP3.
Nothing is redesigned, re-generated or substituted – see [docs/AUDIT.md](docs/AUDIT.md).

## Run
```bash
npm install
npm run dev          # browser preview  → http://localhost:5173
```
Preview controls: **Play / Pause** (Space), **Replay**, **timeline scrubber** (← / → = ±1 s), mute.
`?t=31.2` opens at a given second; `?render=1` shows the bare 1080×1350 stage.

## Export MP4 (H.264 + AAC)
```bash
npm run build
npm run export                                   # → out/sacrifice-of-praise-26.mp4 (use --out to rename)
npm run export -- --crf 16 --workers 2           # options: --out --workers --crf --preset --from --to (frames)
```
Needs `ffmpeg` and Chromium (Playwright's; set `CHROMIUM_PATH=/path/to/chrome` if it isn't installed – `npx playwright-core install chromium`).
Each frame is rendered by *seeking* the timeline, so the result is frame-exact regardless of machine speed.
Output: High profile, yuv420p, BT.709, AAC-LC 192 kbps, `+faststart`.

## Where to edit things
| What | File |
|---|---|
| **All timings** (cue per reveal, glints, shimmers, camera, particles) | `src/config/timing.ts` |
| Choreography (how each reveal moves) | `src/engine/timeline.ts` |
| Layer manifest (ids, offsets, blend modes, depth) | `src/config/layers.json` (generated by `tools/build_manifest.py`) |
| Camera / parallax / glare breathing | `src/engine/player.ts` |
| Particles | `src/engine/particles.ts` |
| Glint / shimmer / sweep styling | `src/styles.css` |
| Audio analysis | `tools/analyze_audio.py` → `src/config/audio-analysis.json` |

`tools/` also has `contact_sheet.py` and `verify_stack.py` (audit helpers; need Python + Pillow + psd-tools).
Layer PNGs and the soundtrack are copied to `public/assets` (git-ignored) by `npm run sync-assets`, which runs automatically before `dev` / `build`.

## Notes for review
* Nothing is deployed or published; output is local (`out/`, git-ignored).
* Non-host portraits are referred to by position only – the files don't say which artiste is which.
* The lower half of the frame stays light/empty for the first ≈10 s while the portraits build from the top, as the brief orders the scenes. Easy to change in `timing.ts` if you'd prefer the choir or harps earlier.
